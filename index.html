4 · System guide

Live visual preview

Audio-reactive graphics are rendered locally. No internet, streaming, or DJ mixer connection required. Press 1–4 to switch scenes; Space pauses/resumes animation. The app uses a shared live canvas feed for the projector window.

Pre-party checklist

Test microphone permission, music sensitivity, scene changes, HDMI projector output, and projector latency on the actual show laptop. Plug the laptop into power; disable sleep and notifications. Avoid pointing the projection beam into DJs' eyes. If microphone permission fails, launch through localhost using the included starter scripts.

Performance note: Built-in microphone processing, speaker-to-microphone distance, display refresh, and projector image processing all add delay. Low-latency processing is used, but zero latency cannot be guaranteed.
